## 소개

국내 금융권 최초로 MySQL 기반 대규모 분산 데이터베이스를 설계·구축해 **초당 수만 건의 트랜잭션과 수백 대의 운영 DB**를 무장애로 운영했고, 반복적인 운영 업무는 자동화해 루틴한 업무의 약 90%를 시스템이 수행하도록 만들었습니다.

이후 관심을 **데이터의 저장에서 흐름으로** 확장해, Oracle/MySQL/PostgreSQL의 대용량 변경 데이터를 실시간으로 서비스에 제공하는 자체 CDC 플랫폼과 Kafka 기반 초당 100만 건 규모의 데이터 처리 환경을 구축·운영했습니다.

특정 기술이나 소스·타깃에 국한되지 않고, 데이터가 필요한 곳으로 안정적이고 자유롭게 흐를 수 있는 데이터 생태계를 만드는 것을 지향합니다.

## 주요 성과

- **초당 수만 건 이상**을 처리하는 MySQL 샤딩 데이터 플랫폼 구축
- **수백 대 이상**의 운영 데이터베이스 무장애(4년) 운영
- 반복적인 DB 운영 업무 **약 90% 자동화**
- Kafka 기반 **초당 100만 건** 메시지 처리 환경 구축

## 주요 경험

### 카카오뱅크 데이터베이스 구축
- 카카오뱅크 초기 MySQL 아키텍처 설계 및 구축
- 초당 수만 건 이상을 처리하는 샤딩 구조 설계
- 수백 대 이상의 운영 DB 관리
- 설계, 구축, 운영, 장애 대응, 성능 최적화 전 과정 담당
- 서비스 런칭 이후 무장애 운영
- 구축 경험과 기술을 외부 컨퍼런스에서 공유

### 데이터베이스 운영 자동화
- 반복적인 DB 운영 업무의 약 90% 자동화
- 모니터링, 알림, 점검 등 반복 업무 시스템화
- Prometheus / Grafana 기반 모니터링 환경 구축
- 단순 반복 업무를 약 10% 수준으로 축소

### CDC 및 데이터 파이프라인
- Oracle / MySQL / PostgreSQL 이기종 데이터 동기화 목적
- 자체 CDC 엔진 및 플랫폼 설계 및 개발
- 실제 서비스 환경 적용 및 운영 (초당 수만건)
- DB 변경 데이터를 다양한 서비스에 실시간 제공
- BI 망연계 데이터 파이프라인 구축 및 운영

### Kafka / 빅데이터 플랫폼
- Kafka 기반 실시간 데이터 플랫폼 구축
- 초당 100만 건 규모의 메시지 처리 환경 구현
- CDC와 Kafka를 연결한 실시간 데이터 파이프라인 구축
- 빅데이터 플랫폼 개발 및 운영
